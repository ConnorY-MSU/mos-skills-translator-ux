# MOS Skills Translator: UX Design Process (Stages 1 to 4)

CSCI 443 UX Design Thinking course project by Connor Yetter.

**Live report:** https://connory-msu.github.io/mos-skills-translator-ux/

- `index.html`: full report (Stages 1 to 4) with the embedded interactive prototype
- `prototype/index.html`: clickable high-fidelity prototype (HTML/CSS/JS, no build step)
- `docs/`: Stage 3 and Stage 4 write-ups (.docx)
- `assets/`: empathy maps, business model canvas, sketches, mind map, screenshots
- `source/`: HTML sources used to render the sketch, mind map, sticky-note, and annotation images
